🎨 Project Overview

This project involves building a fully responsive landing page for a headphones brand using pure HTML and CSS—no frameworks, no JavaScript.

You are expected to recreate both the desktop and mobile layouts exactly as shown in the Figma file, respecting spacing, colors, typography, and component structure.

The final result should be neat, clean, accessible, and professional.

🖥️ Figma Design

To complete this project, you must duplicate the Figma design into your workspace.

How to set it up:

Create or log in to your Figma account.

Open the design file.

Click “Duplicate to your Drafts” to unlock all layers, sizes, and properties.

Inspect the design using the right-hand Inspect Panel (for CSS values, spacing, fonts, etc.).

If you cannot access the original design, use the provided backup file from ALX.

🛠️ Technical Requirements
General

The project lives in the directory headphones/

You must use semantic HTML elements.

Your layout must match the Figma design as closely as possible.

Some values in the Figma file may be decimals—round them as needed.

Responsiveness

The design must switch to the mobile layout when the screen width is 480px or less.

Content width must be max 1000px, horizontally centered.

Styling

No external CSS libraries allowed (Bootstrap, Tailwind, etc.)

Only font-family declarations using the required fonts.

You must use the exact colors and spacing from the Figma design.
